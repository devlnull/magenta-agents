# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be helpful, and assume good intent. Harassment and personal attacks are not accepted in issues, pull requests, or discussions.

To report a problem, contact the maintainer through the [security advisory form](https://github.com/devlnull/magenta-agents/security/advisories/new) or by a private message on GitHub (@devlnull). Reports are confidential.
