Magenta 0.10.0 makes the checks work with Claude Code itself: no more "Stop hook error" while the agents work, and commands to check and approve from the prompt.

## No false blocks while the agents work

- Magenta now knows which subagents of the task still run (SubagentStart and SubagentStop hooks). While the lead works in the background, the conductor can wait, and the Stop hook does not block. When the lead returns, the checks count again.
- A maker (Engineer, Front-End, Platform, Writer) that changed the code cannot return until the checks of the task pass, so the conductor gets verified work. After two tries, the maker returns and reports the problem.
- When the Stop hook blocks, it uses a structured decision: Claude gets the reason, and you see a short note.

## Commands in Claude Code

| Command (plugin) | What it does |
|---|---|
| `/magenta:task-status` | The active task, the checks and their approval, and the result for the current code |
| `/magenta:run-checks` | Runs the checks now and shows the result table |
| `/magenta:approve-checks` | Shows the waiting checks and asks you to approve them in the permission dialog |

## Upgrade

1. Plugin: `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`. Installer: run it again, then run `magenta.py init <repo>` again in each repository (it adds the new hooks).
2. Restart Claude Code.
