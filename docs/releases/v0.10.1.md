Magenta 0.10.1 makes the Stop hook quieter.

- The Stop hook sends Claude back one time for each state of the code and of the results. While nothing changes, for example while Claude waits for your answer, it does not repeat the same message. A new change of the code gives a new reminder.
- Since 0.10.0: the hook waits while a subagent of the task still works, makers verify before they return, the block is a short note and not a "Stop hook error", and you can type `/magenta:task-status`, `/magenta:run-checks`, and `/magenta:approve-checks`.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code. A session that started before the update keeps the old hooks.
3. Check the version: `claude plugin list`, or `/plugin` in Claude Code.
