Magenta 0.12.0 lets a task run to the end without the human, and shows only the result of the task.

- **Auto mode.** `/magenta --auto <task>`. Magenta allows each tool call of the task that passes its rules, so Claude Code does not ask for each one. You decide only at the checks gate (one approval), at a blocker, and at the done gate. Blocked calls stay blocked, and `approve` and `--force` always ask.
- **Only the result.** The conductor talks to you only for questions, the checks to approve, and the final report. Each agent returns a short Result block. The hooks answer with decisions, not with "hook errors", and show you a note only when you must act.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code. A session that started before the update keeps the old hooks.
3. Check the version: `claude plugin list`, or `/plugin` in Claude Code.
