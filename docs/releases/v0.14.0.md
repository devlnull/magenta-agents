Magenta 0.14.0 adds QA to a task only when the task needs it.

- QA joins for tests, features and visible behavior changes, money, security, personal data, data migrations, performance targets, and changed code without tests.
- For other tasks, the lead writes the tests of its change before the change. The tests are locked, and you approve them with the checks.
- Evaluation (30 scenarios, 3 runs each, blind judge): QA took part 24% less, never where it was not wanted, and was never missing where it was needed. The plans won 51 to 26 against 0.13.0 (13 ties). See `evals/driver/results.md`.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code.
