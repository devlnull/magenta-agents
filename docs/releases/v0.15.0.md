Magenta 0.15.0 gives better results with about a third of the tokens.

- **Direct mode:** small, clear tasks run in the conductor itself, with the project checks and the Stop hook, without other agents.
- **A rule and caller scan by a script** (`verify context`): the conductor finds the rule files of the repository and the callers of the changed code before it selects the mode. No model tokens.
- **Fewer turns and a short conductor:** `verify begin`, `gate`, and `close`; a 15 KB conductor skill; one line when all checks pass.

Benchmark (14 tasks, 4 Claude models, hidden tests, one run each): 0.15 passed 96.3% of the hidden tests (0.14: 95.3%; a plain prompt: 93.4%) with 68% fewer tokens and 64% lower cost than 0.14. See `evals/benchmark/README.md`.
