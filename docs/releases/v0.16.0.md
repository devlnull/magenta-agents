Magenta 0.16.0 makes the mode decision safer and uses Sonnet as the default strong model.

- **Direct mode by a script verdict:** `verify context` says if direct mode is allowed. Rule files, money, security, personal data, stored formats, and shared callers make it "Not allowed".
- **Follow the rules exactly:** the conductor keeps the names, exception types, and formats of the repository, and writes its own ideas in the report.
- **Sonnet as default:** `reasoning-high` and `reviewer-alt` use `sonnet` on Claude Code.
- **A benchmark at each release:** the results of each version are in `evals/benchmark/results/`, with the images in the README. The release workflow stops when the benchmark of the version is missing.
- **Fixes:** `verify context` keeps all the lines of a rule, and finds the callers on macOS. The guard allows verify commands on Windows. The fingerprint sees an edit of the same size in the same second.

Benchmark (18 tasks, 4 of them held out, 4 Claude models, 3 runs each, hidden tests):

| | Plain prompt | Magenta 0.16 |
|---|---:|---:|
| Hard tasks (hidden rules) | 87.9% | **96.6%** |
| All tasks | 94.1% | **95.8%** |
| Sonnet 5.5, all tasks | 99.2% | **100%** ($0.14 for each task) |
| Old tests still pass | 210 of 216 | **214 of 216** |

On simple and held-out tasks, a plain prompt was better (99.0% against 96.9%, and 93.7% against 90.6%). See `evals/benchmark/README.md`.

2. Restart Claude Code.
