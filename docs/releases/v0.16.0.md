Magenta 0.16.0 makes the mode decision safer and uses Sonnet as the default strong model.

- **Direct mode by a script verdict:** `verify context` says if direct mode is allowed. Rule files, money, security, personal data, stored formats, and shared callers make it "Not allowed".
- **Follow the rules exactly:** the conductor keeps the names, exception types, and formats of the repository, and writes its own ideas in the report.
- **Sonnet as default:** `reasoning-high` and `reviewer-alt` use `sonnet` on Claude Code.
- **Fix:** `verify context` keeps all the lines of a rule.

Benchmark (18 tasks, 4 of them held out, Sonnet 5.5 and Haiku 4.5, 3 runs each, hidden tests): 0.16 passed 93.1% (a plain prompt: 91.4%), and it kept all original tests (plain: 106 of 108). Sonnet 5.5 passed 100%. The cost is about two times the cost of a plain prompt. See `evals/benchmark/README.md`.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code.
3. If you changed `models.yaml`, keep your values.
