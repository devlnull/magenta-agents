Magenta 0.16.1 makes the default mode real.

In 0.16.0, the conductor often worked alone also on risky changes: with Sonnet 5.5 in all risky runs of the benchmark, and with Haiku 4.5 in most of them. It skipped the checks gate, the lead agent, and the review. You saw no subagents.

Now the scripts enforce the mode. When the rule scan of the changed code says that direct mode is not allowed (a rule file, money, security, personal data, a stored format, shared callers), the task closes only when:

- checks of the task are approved (you approve them at the checks gate), and
- in Claude Code, a review agent ran (for example QA, Security, or the Architect).

Until then, `verify close` and the Stop hook keep the task open and say what is missing. You can close it without them: `finish --force`.

Benchmark (18 tasks, 4 Claude models, 3 runs; new runs for Sonnet 5.5 and Haiku 4.5):

| | 0.16.0 | 0.16.1 |
|---|---:|---:|
| Runs with subagents (Sonnet 5.5 and Haiku 4.5) | 11 of 108 | **82 of 108** |
| Risky runs without a review | 53 of 62 | **0 of 67** |
| Hidden tests, all models | 95.8% | **96.4%** |
| Hidden tests, Haiku 4.5 | 86.1% | **89.2%** |
| Hidden tests, Sonnet 5.5 | **100%** | 99.2% |
| Cost for each task, all models | **$0.50** | $0.69 |

The process costs more: Sonnet 5.5 $0.14 → $0.44 for each task. A plain prompt costs $0.11 and passes 94.1%.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code.
