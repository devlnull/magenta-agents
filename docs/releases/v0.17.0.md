Magenta 0.17.0 removes the approval dialog from auto mode.

In 0.16.1, an `--auto` task still asked you to approve the checks and each `--force`. One task on a real repository showed the dialog 75 times.

Now, in a task that you start with `/magenta --auto`, the conductor approves the checks and runs `--force` itself. It reads each check first. It writes each approval and each `--force` in the brief, and the final report lists them. The task can run for hours without you.

The other guardrails stay:

- Other subagents still get the dialog. The Magenta agents still cannot approve.
- The state files of the verify script, `.magenta/`, and the locked tests stay protected.
- A task without `--auto` asks you, as before.

If you ran `magenta.py init` in a repository, its ask rules in `.claude/settings.local.json` still show the dialog. Claude Code applies ask rules before hook decisions. Remove the `verify.py` and `magenta.py` ask rules from that file to get no dialog there.

## Upgrade

1. `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`.
2. Restart Claude Code.
