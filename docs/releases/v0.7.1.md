The first published release of Magenta Agents: six role-based AI agents (Product Manager, Software Architect, Senior Principal Engineer, QA Engineer, Software Engineer, and Front-End Engineer) for Claude Code, with entry points for OpenCode, Codex CLI, and Gemini CLI.

## What it does

- `/magenta <task>` runs any daily task: a bug, a performance target, a refactor, an investigation, a review, an incident, an upgrade, tests, a design, or a feature.
- **Verify first** ([ADR-0012](https://github.com/devlnull/magenta-agents/blob/main/docs/adr/0012-verify-first.md)). QA and the Architect write the success criteria and the rules as checks. You approve the checks. One lead agent works until the checks pass. One to three reviewers read the diff.
- In Claude Code, a Stop hook does not let the agent finish while an approved check fails. Guard hooks keep each agent in its own files and commands.
- Team mode (`--team`) runs the full playbooks for PRDs, contract changes, security, and other high-risk work.

## Install

- **Claude Code plugin:** `claude plugin marketplace add devlnull/magenta-agents`, then `claude plugin install magenta@magenta-marketplace`.
- **Installer:** `curl -fsSL https://raw.githubusercontent.com/devlnull/magenta-agents/main/install.sh | sh -s -- --ref v0.7.1` (Windows: `install.ps1`).
- **Offline:** unzip `magenta-agents-0.7.1.zip`, then run `python3 magenta.py install` and `python3 magenta.py init <repo>`.
