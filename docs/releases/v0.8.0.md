Magenta 0.8.0 extends the team with five roles. Each one owns one kind of risk, turns it into checks, and joins a task only when its area is at risk ([ADR-0013](https://github.com/devlnull/magenta-agents/blob/main/docs/adr/0013-extended-team.md)).

## New roles

| Agent | Type | What it does |
|---|---|---|
| Site Reliability Engineer (`sre`) | reviewer | SLOs and alerts, resilience and rollout review, incident lead, runbooks and postmortems |
| Platform Engineer (`platform`) | maker | CI/CD pipelines, containers, Kubernetes and Helm, Terraform. Never applies or deploys. |
| Security Engineer (`security`) | reviewer | Threat models, secure code review, CVE triage, scanner rules as checks |
| Database Engineer (`database`) | advisor | Zero-downtime migration plans, query tuning, migration and query checks |
| Technical Writer (`writer`) | maker | Documentation, READMEs, changelog, and release notes in ASD-STE100 style |

## Also new

- Task types `infrastructure`, `reliability`, `data`, and `docs`, with playbooks. SRE, Security, and Database review lenses.
- Ten skills and five templates (reliability, security, data, runbook, postmortem).
- Stricter file ownership: only the Platform Engineer changes CI pipelines, container and deployment files, and infrastructure code. Only the Security Engineer changes scanner rules and ignore files.

Read [the team](https://github.com/devlnull/magenta-agents/blob/main/docs/team.md) for when each role joins and which files it owns. The [changelog](https://github.com/devlnull/magenta-agents/blob/main/CHANGELOG.md) lists all changes.

## Upgrade

- Plugin: `claude plugin marketplace update magenta-marketplace`.
- Installer: run the installer again.

If a repository needs the old ownership (for example the Engineer changes the Dockerfile), add a rule to `.magenta/policy.json`.
