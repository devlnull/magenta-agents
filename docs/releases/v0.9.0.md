Magenta 0.9.0 makes the approval of checks one click, and fixes the findings of a full audit of the repository.

## Approve in the dialog of Claude Code

At the checks gate, Magenta shows the new checks as a table and requests the approval. Claude Code opens its permission dialog, with each check and its command. Select **Yes** to approve, or **No** to ask for changes. You no longer type a long command with the path of the plugin.

- No model can approve alone: subagents are blocked, and the main session needs your confirmation in the dialog.
- `magenta.py init` adds ask rules to `.claude/settings.local.json`, so that the dialog appears in every permission mode, also with `--dangerously-skip-permissions`.
- The same dialog confirms `--force`, when you decide to close or replace a task with failing checks.

## Fixes from the audit

The guard, the protect hook, the code fingerprint, the YAML parser, file ownership, the runner, the CI templates, and the installers got many fixes. The [changelog](https://github.com/devlnull/magenta-agents/blob/main/CHANGELOG.md) lists them.

## Upgrade

1. Plugin: `claude plugin marketplace update magenta-marketplace`, then `claude plugin update magenta@magenta-marketplace`. Installer: run it again.
2. Run `python3 ~/.magenta-agents/magenta.py init <repo>` again in each repository (with `--no-hook` for the plugin), to add the ask rules.
3. Restart Claude Code.
