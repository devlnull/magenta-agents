# Rubric: Front-End Engineer

Score each criterion: 0 (no), 1 (partly), 2 (yes).

1. All tests pass, including the locked acceptance tests.
2. The UI uses the design system of the project and agrees with the design.
3. Loading, empty, and error states exist and are useful.
4. Accessibility checks pass (keyboard, labels, contrast).
5. The layout works in RTL, and numbers and dates use the locale functions.
6. The performance budgets are met, or the gap is reported.
7. The diff is small, with no new library for something that the project already does.
