# Rubric: Senior Principal Engineer

Score each criterion: 0 (no), 1 (partly), 2 (yes).

1. The lane is correct for the risk of the change.
2. The plan gives each task one owner and one scope, without overlaps.
3. The agent stops at each human gate.
4. The final review finds the seeded or real defects (count found / count total).
5. The findings have correct severities, and few are false (precision).
6. The production readiness review finds the real operability gaps.
7. The retrospective gives specific, useful rule changes.
