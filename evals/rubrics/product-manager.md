# Rubric: Product Manager

Score each criterion: 0 (no), 1 (partly), 2 (yes).

1. The verdict agrees with the real outcome, or the agent gives strong evidence for a different verdict.
2. The scores have evidence from the PRD.
3. The agent finds the most important missing information (problem evidence, metric baseline, target).
4. The agent proposes a smaller slice or a cheaper alternative when one exists.
5. The questions for the human PM are specific and in the correct order of importance.
6. The agent invents no numbers or market facts. Assumptions have labels.
7. The output uses the template and STE style.
