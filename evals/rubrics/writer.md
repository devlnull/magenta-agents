# Rubric: Technical Writer

Score each criterion: 0 (no), 1 (partly), 2 (yes).

1. Each change of behavior in the diff has its documentation.
2. Each command, option, and example agrees with the code.
3. Each page has one document type (tutorial, how-to, reference, or explanation).
4. The text follows ASD-STE100: short sentences, active voice, one instruction in each sentence.
5. Links work, and diagrams are in Mermaid and render.
6. The changelog entry is correct and written for the user.
